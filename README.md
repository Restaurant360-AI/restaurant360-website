# Restaurant360 website

Marketing site for [Restaurant360 AI](https://github.com/Restaurant360-AI/restaurant360-ai), served at
`restaurant360ai.com` through GitHub Pages.

This repository is public. Keep it to marketing content only: no internal documentation, credentials or customer data.
The application lives in `restaurant360-ai`, and DNS for the domain is managed in `restaurant360-infra`.

Status: placeholder page.

## Design

Light theme modeled on a clean, single-page product layout: soft gradient hero, colored panels with product
illustrations, pill buttons, and a short contact form. The brand colors come from the app (emerald `#10b981`, deep ink
`#0a2a22`). Headlines use Poppins, self-hosted in `fonts/` (SIL Open Font License), so visitors make no Google Fonts
requests. Illustrations in `images/` are SVG with sample data and are labeled as such.
